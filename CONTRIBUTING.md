# Contributing

## Tentang Repository

Repository ini merupakan **proyek skripsi dan penelitian pribadi**.

Source code digunakan sebagai bagian dari proses penelitian, pengembangan, pengujian, dokumentasi, dan penyelesaian karya akademik.

## Kontribusi

Repository ini **tidak menerima kontribusi kode dari pihak luar**.

Oleh karena itu:

* Pull Request tidak dibuka untuk kontribusi umum.
* Perubahan source code dilakukan oleh pemilik repository.
* Issue tidak dimaksudkan sebagai forum pengembangan bersama.
* Fork repository tidak memberikan hak untuk menggunakan atau mendistribusikan source code.
* Tidak ada izin untuk membuat karya turunan berdasarkan source code tanpa persetujuan pemilik.

## Pelaporan Masalah

Jika menemukan kesalahan atau potensi masalah, informasi dapat disampaikan kepada pemilik repository melalui:

https://github.com/mousesalt

Untuk masalah yang berkaitan dengan keamanan, silakan lihat [`SECURITY.md`](SECURITY.md).
